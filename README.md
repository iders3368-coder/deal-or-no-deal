# 一掷千金 - Deal or No Deal

抖音小程序小游戏，模仿外国综艺节目《一掷千金》。

## 游戏规则

1. 游戏开始时，玩家从26个盒子中选择一个作为自己的盒子
2. 每轮打开指定数量的盒子（从6个递减到1个）
3. 每轮结束后，银行家会出价购买玩家的盒子
4. 玩家可以选择"成交（Deal）"接受出价，或"继续（No Deal）"拒绝出价
5. 如果玩家拒绝所有出价，最终将获得自己盒子中的金额

## 金额配置

26个盒子中包含以下金额（单位：元）：
- 小额：0.01, 0.1, 0.5, 1, 5, 10, 20, 50
- 中额：100, 200, 300, 400, 500, 750, 1000, 2000
- 大额：3000, 4000, 5000, 7500, 10000, 15000, 20000, 35000, 50000, 100000

## 使用方法

1. 使用抖音开发者工具导入项目目录
2. 在抖音开发者工具中点击"预览"按钮
3. 或使用"真机调试"在手机上测试
