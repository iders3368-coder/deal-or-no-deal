# 旧版 H5 原型（仅作对照）

这个目录保存的是改造前的 H5 页面版本，包含 DOM/CSS 实现和旧的逻辑代码。它**不属于**抖音小游戏包，`project.config.json` 已通过 `packOptions.ignore` 排除整个目录。

用途：
- 对照旧版玩法与视觉效果。
- 需要时运行 `start.bat` 在 `http://127.0.0.1:3002/` 查看。

注意：
- 旧版存在终局崩溃、轮次合计 26 次、讨价还价事件重复绑定等问题，未在此目录完整修复。
- 正式版本请使用项目根目录的 `game.js` + `src/` Canvas 实现。
- `server.js` 已修复路径穿越，只监听 `127.0.0.1`。
